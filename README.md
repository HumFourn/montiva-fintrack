# Montiva FinTrack

Aplikasi desktop untuk mencatat dan memantau keuangan pribadi secara sederhana dan terstruktur.

## Fitur
- Catat pemasukan dan pengeluaran dengan kategori
- Lihat grafik tren keuangan mingguan dan bulanan
- Riwayat transaksi lengkap dengan filter tanggal
- Kategori kustom sesuai kebutuhan
- Akun pengguna — data aman dan tersinkron antar perangkat

## Cara Install
1. Download file `.zip` di halaman [Releases](../../releases)
2. Ekstrak file menggunakan WinRAR, 7-Zip, atau Windows bawaan
3. Buka folder hasil ekstrak, jalankan file aplikasi Montiva
4. Daftar akun untuk mengaktifkan sinkronisasi data

## Persyaratan
- Windows 10 atau lebih baru (64-bit)
- Koneksi internet untuk sinkronisasi akun

## Lisensi
Gratis untuk penggunaan pribadi.
